はじめの設定

親指キーがどのキーかは、キーボードと OS で違います。実際に押して覚えさせてください。

この画面は物理キーボードで使います

親指シフトは、文字キーと親指キー（英数／かな）を同時に押して入力します。 画面上のソフトキーボードでは押した時刻の差が取れないため、設定も試し打ちもできません。 パソコンで開くか、外付けキーボードをつないでください。

日本語入力（IME）は OFF にしてください

IME が ON だと、このページに届く前に OS が文字を作ってしまい、押下の時間差が測れません。 英数 / 半角/全角 で直接入力に切り替えてください。

親指シフトのエミュレータは、一旦止めてください

macOS なら Lacaille や Karabiner の NICOLA 設定、Windows なら やまぶきR・DvorakJ です。これらが動いていると、キーが二重に届いたり、 押下の時刻が書き換わったりします。とくに Karabiner の simultaneous は最初のキーを一旦飲み込んでから出し直すので、 押下の時間差そのものが失われます。この道場は自前で同時打鍵を判定するので、 練習中は止めておくのが確実です。

1. 親指キーを覚えさせる

左親指キー 英数（Lang2）
右親指キー かな（Lang1）

既定は、macOS の JIS キーボードで実測した 英数（Lang2・スペースの左）と かな（Lang1・スペースの右）です。 ちょうど親指の下にあり、押下も解放も取れて、IME に横取りされないことを確認しています。 Safari では かな が KanaMode として届きます。

Space は親指キーには使いません。文字キー側で使う可能性があるためです。 別のキーを親指に割り当てたいときは、上のボタンから覚えさせてください。

2. 打ち方のクセ

同時打鍵の判定をどこまで緩めるか。思ったとおりに同時押しが通らないときは、まずここです。

3. 重なりの下限

文字キーを先に押したとき、親指とどれだけ重なっていれば同時打鍵と認めるか。 既定は 80ms（NICOLA 規格の考え方に合わせています）。 数字を大きくするほど厳しくなります（重なりがそれ未満だと別々の打鍵とみなす）。 通らないときは詰めてください。

80ms

4. 打鍵音

判定は音でも返します。親指が先行していれば低い音から高い音へ、 遅れていれば高い音から低い音へ鳴り、ぴったり合うと二つが融けて一つの音に聞こえます。 画面を見ていなくても、耳だけで «早いのか遅いのか» が分かります。 既定は無音です。下の「5. 試し打ち」でそのまま確かめられます。

音色

選ぶとその場で一度鳴ります。🔒 の付いた音色は、書いてある条件を満たすと選べるようになります。

40

動かすと、その音量で一打だけ鳴ります。0 にすると鳴りません（無音と同じ扱いです）。 単独打鍵はいちばん小さく、同時打鍵は少し大きく、課題を打ち切ったときだけはっきり鳴ります。

5. 試し打ち

記録は残りません。設定が効いているか、ここで確かめてください。音を入れていれば、ここでも鳴ります。

      NICOLA 配列表

      1 つのキーに 3 つの面があります。単独で押した面、同じ側の親指と押した面、逆側の親指と押した面。

      • 単独打鍵
      • 逆側の親指（交差シフト） → 主に濁音・半濁音
      • 同じ側の親指（同側シフト） → 別のかな

      色は「左シフトか右シフトか」ではなく、同じ側の親指か、逆側かで分けています。 NICOLA には「逆側の親指なら主に濁音・半濁音、同じ側の親指なら別のかな」という規則があるので、 その規則がそのまま目に入るようにしてあります。左右のどちらの親指かは、面の置かれた位置で分かります。

      たとえば左手の し は、右親指と打てば じ（交差＝濁音）、 左親指と打てば あ（同側＝別のかな）になります。 左手のキーは右の面が、右手のキーは左の面が濁音側です。
